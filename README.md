# 迷你横版冒险

一个受超级马里奥启发的简易横版小游戏。你可以向右探索关卡、跳过小怪、顶破砖块，并且吃蘑菇变大。现在提供三个连续关卡，每关结尾都有一只 boss 守候。

## 如何游玩

1. 直接用浏览器打开 `index.html`（双击文件或拖入浏览器标签页即可）。
2. 使用键盘操作：
   - ←/→ 或 A/D：移动。
   - 空格、↑ 或 W：跳跃。
   - Enter：向当前朝向发射骨头子弹。

踩到小怪可以将它消灭。顶到问号砖会掉落蘑菇，吃掉后主角会变大。Boss 需要吃下 5 发子弹才会倒下，倒下后旗帜会升起并带你进入下一关。掉进深坑或被敌人碰到会从第一关重新开始。
